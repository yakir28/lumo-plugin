# Lumo

Lumo makes finished MP4 films on this computer: edits of the user's own footage in a named style (Glare, Punch, Luxe, Story) and launch films for a product. The Lumo app runs on localhost and shows every film, its progress and its versions.

You direct the films with the `lumo` tools. For a film asked here, start with `lumo_new_film`; for films asked in the app, run `/lumo:studio`. Then read `lumo_guide('director')` and follow it to the end.

If a tool says Lumo isn't set up, run `/lumo:setup`.
