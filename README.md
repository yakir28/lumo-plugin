# Lumo Plugin for Claude Code

Lumo makes finished videos on your own computer, directed by your own Claude: edits of your talking-head
and podcast footage in a named style, and launch films for your product, with motion graphics, music and
sound. Your videos stay on your computer.

The plugin needs a Lumo Plugin subscription: [try-lumo.com](https://try-lumo.com).

## Install

In Claude Code:

```
/plugin install lumo --marketplace yakir28/lumo-plugin
```

Then:

1. `/lumo:setup` connects this computer to your Lumo account (you approve it on try-lumo.com) and installs
   Lumo's editor (about 3 GB, a few minutes). macOS for now.
2. `/lumo:studio` opens Lumo on your computer. Ask for a video there, or in the chat.
